O QUE É
--------
`/teste` é um quiz de captação de leads: pais respondem sobre o
comportamento do filho, veem um retrato inicial na tela e a
idealizadora recebe o lead por e-mail (Brevo) para prospectar a
Clínica. `/admin` é o painel privado dela para ver todos os leads,
gerar um resumo com IA (Google Gemini) sobre cada resultado e
reenviar esse resumo ao responsável por e-mail.

ARQUIVOS NOVOS
----------------
- teste.html            → landing + quiz (público)
- teste-perguntas.json  → perguntas/faixas do quiz (editável sem deploy
                           de função; ver abaixo)
- admin.html            → painel da idealizadora (login + lista de leads)
- supabase/functions/behavior-test-webhook/  → recebe as respostas do quiz
- supabase/functions/behavior-test-admin/    → login, listagem, insight IA
- supabase/migrations/20260914*.sql          → tabelas no Supabase

BANCO (projeto Supabase ivjvpdzsfjdpyabbzzuj)
-------------------------------------------------
- fa_leads_teste_comportamento → um registro por família (RLS ligado,
  sem policy pra anon — só as Edge Functions, via service role, leem
  e escrevem).
- fa_teste_admin_users / fa_teste_admin_sessions → login do painel.

TROCAR O CONTEÚDO DO TESTE (perguntas/faixas reais)
--------------------------------------------------------
1. Editar teste-perguntas.json (perguntas, escala de respostas, faixas
   de resultado). Trocar "version" para uma data nova quando o
   conteúdo mudar de verdade.
2. Copiar a MESMA lista de perguntas (QUESTION_IDS) e faixas (BANDS) e
   o mesmo "version" (TEST_VERSION) para dentro de
   supabase/functions/behavior-test-webhook/index.ts — o score é
   sempre recalculado no servidor, nunca confia no que vem do
   navegador. Se as versões não baterem, o site pede pra recarregar.
3. Reimplantar a função (`deploy_edge_function` via MCP, ou
   `supabase functions deploy behavior-test-webhook` pela CLI).

MCP DO SUPABASE NÃO CONFIGURA SECRETS — isso é um limite real da
ferramenta usada nesta conversa: ela aplica migração e faz deploy de
função, mas não tem uma chamada para gravar Edge Function Secrets.
Os itens abaixo precisam ser feitos manualmente por você, uma vez só,
pelo painel do Supabase (https://supabase.com/dashboard/project/ivjvpdzsfjdpyabbzzuj/functions/secrets)
ou pela CLI (`supabase secrets set NOME=valor --project-ref ivjvpdzsfjdpyabbzzuj`).
